實作步驟 ‧ 跟著投影片走

五個步驟，一次一個

每一步都有「過關條件」。過關了就等大家，沒過關先看「卡住了」分頁，再問旁邊的人，再舉手。

1

拿一把金鑰

AI 餐廳的會員卡。沒有它，服務生不會理你。
  1. 開 console.groq.com，用 Google 帳號登入
  2. 左側點 API Keys → Create API Key，名稱隨便取（例如 class）
  3. 複製那串 gsk_ 開頭的金鑰，先貼到記事本。它只會顯示一次。

過關條件：記事本裡有一串 gsk_ 開頭的文字。

金鑰就是你的密碼。不截圖、不貼群組、不放進講義。課後回 Groq 刪掉重建。

2

用滑鼠跟 AI 說第一句話（Postman）

一個請求只有四個零件：網址、方法、標頭、內容。
  1. Postman 裡按 New → HTTP，方法選 POST，貼上網址
  2. Headers 分頁新增一列：Key 填 Authorization，Value 填 Bearer 你的金鑰（Bearer 後面一個空格）
  3. Body 分頁選 raw，右邊格式選 JSON，貼上下面那段，按 Send
網址
https://api.groq.com/openai/v1/chat/completions
方法
POST
Headers
Authorization: Bearer gsk_你的金鑰
BODY ‧ RAW ‧ JSON
{
  "model": "qwen/qwen3-32b",
  "messages": [
    {"role": "user", "content": "用一句話介紹你自己"}
  ],
  "reasoning_effort": "none"
}

過關條件：右上角狀態碼是綠色的 200 OK，回應裡 choices → message → content 那一行就是 AI 回你的話。過關的人把「用一句話介紹你自己」改成任何一句，再按一次 Send。

3

同一件事，改用 Colab 做

Colab 只要會三件事：存副本、貼金鑰、由上往下按播放鍵。
  1. 打開講義裡的 Colab 筆記本連結，按 檔案 → 在雲端硬碟中儲存副本（沒存副本改不了內容）
  2. 第一格把金鑰貼在引號中間，前後不留空格
  3. 每一格左邊的 ▶ 由上往下按，等它轉完再按下一格。第一次會跳「這不是 Google 建立的筆記本」，按仍要執行。
筆記本 STEP 3 ‧ 跟 POSTMAN 做的是同一件事
import requests

URL = "https://api.groq.com/openai/v1/chat/completions"
headers = {"Authorization": "Bearer " + GROQ_API_KEY, "Content-Type": "application/json"}
body = {"model": "qwen/qwen3-32b", "reasoning_effort": "none",
        "messages": [{"role": "user", "content": "用一句話介紹你自己"}]}

r = requests.post(URL, headers=headers, json=body, timeout=60)
print(r.json()["choices"][0]["message"]["content"])

對照看：URL 就是剛剛貼的網址、post 就是剛剛按的 Send、r.json() 就是剛剛看到的回應。

過關條件：這一格下面印出 AI 回的一句話。上半場完成。

4

寫班級公約，讓它記得對話

AI 本身不會記得；是我們每次把整本對話紀錄再寄一次，它才「記得」。

4-1 班級公約：只改三個引號中間的中文。三個引號本身不要動。換名字、換年級、加規則都可以。

筆記本 4-1 ‧ 只改綠色的字
SYSTEM_PROMPT = """你是「小助」，一位國小老師的教學小幫手。
對象：國小中年級學生。用字簡單、親切，一律使用繁體中文。
規則：
- 老師沒有提供的資料不要自己編；不確定就說不確定
- 回答用條列，方便老師直接複製使用
- 題目要附答案與一句解析；作文回饋先講優點再講建議，語氣鼓勵
"""
messages = [{"role": "system", "content": SYSTEM_PROMPT}]

4-2 問一句、答一句的函式：這格不用改，按播放鍵就好。三件事：把你的話加進清單、整份清單送出、把回答也記下來。

筆記本 4-2 ‧ 不用改
def chat(user_text):
    messages.append({"role": "user", "content": user_text})      # 1 加進清單
    body = {"model": "qwen/qwen3-32b", "messages": messages,
            "reasoning_effort": "none", "temperature": 0.5}
    r = requests.post(URL, headers=headers, json=body, timeout=60)  # 2 整份送出
    if r.status_code != 200:
        messages.pop()
        return f"（出錯了：{r.status_code}）{r.text[:300]}"
    answer = r.json()["choices"][0]["message"]["content"]
    messages.append({"role": "assistant", "content": answer})    # 3 回答也記下來
    return answer

4-3 聊天迴圈：執行後在輸入框打字、按 Enter；輸入 bye 結束。試試看：先說「我教三年級國語」，再貼一段課文請它摘要，再問「我教幾年級？」。

筆記本 4-3
while True:
    text = input("老師：")
    if text == "bye":
        break
    print("小助：", chat(text))

過關條件：它記得你教幾年級。覺得它講話太深或太淺，回 4-1 改年級，重新執行 4-1 → 4-2 → 4-3。

5

任務卡：餵它真實的材料

這是今天的主菜。

在聊天迴圈裡直接貼上你的課文或作文，再加一句指令。指令都在「任務卡」分頁，有複製按鈕。不滿意就再講一句（「太難了，再簡單一點」、「第 3 題換一題」），它記得前面的內容。

過關條件：做完任何一張任務卡，而且有用「再講一句」修過一次結果。

任務卡 ‧ 任選，做完一張再做下一張

四張任務卡

貼上材料，接著貼指令。貼之前先把學生姓名、座號、家庭狀況拿掉。

任務卡 A ‧ 出題

貼一段課文

根據這段課文，出 5 題選擇題，每題附答案和一句解析。

再講一句：「第 3 題太難，換一題考『為什麼』的。」「加兩題是非題。」

任務卡 B ‧ 作文回饋

貼一篇作文

給這篇三年級作文三個優點、兩個建議，語氣鼓勵，不要幫他改寫。

再講一句：「建議請具體指出是哪一句。」「用學生看得懂的話講。」

任務卡 C ‧ 改寫程度

貼一段太難的文字

把這段改寫成二年級看得懂的版本，不超過 100 字，保留重點。

再講一句：「太難了，再簡單一點。」「改成一年級的版本。」

任務卡 D ‧ 聯絡簿回覆

貼家長的留言

幫我擬一則回覆，語氣溫和、不超過三句，先同理再說明。

再講一句：「再正式一點。」「加一句邀請家長來談。」

課文
小河從山上出發，一路往下跑。它經過樹林，樹葉掉在水面上，像一艘艘小船。它經過田地，農夫用它的水灌溉稻子。它經過村子，孩子們在岸邊洗腳、玩水。最後，小河流進大海。大海好大，小河有點害怕。可是它發現，海裡有好多和它一樣的小河。原來，每一條小河都走過自己的路，最後在這裡見面。

作文
今天早上我一打開窗戶，就看到外面在下雨。雨滴打在窗戶上，發出滴滴答答的聲音，好像在唱歌。我穿上黃色的雨衣，背著書包去上學。路上有很多水坑，我很想踩下去，可是媽媽說會弄濕鞋子，所以我只好小心的繞過去。到了學校，同學的雨傘都放在走廊，紅的、藍的、綠的，像一朵一朵的花。老師說下雨天不能到操場玩，我們就在教室裡下棋。我覺得下雨天雖然不能出去玩，可是也有好玩的地方。

進階與課後

做完了？再往前一步

三個進階題的程式都在筆記本最後面，有興趣再按，不做也完全沒關係。

進階 1

固定輸出格式

在公約裡要求它回表格或 JSON，結果就能直接貼進試算表。

進階 2

一次改一整班

用迴圈把 30 篇作文逐篇送進去，結果存成檔案。批次處理前，學生姓名一律先拿掉。

進階 3

換一家 AI

只改網址和模型名，程式一個字不動。Gemini、千問官方都是同一種格式。

帶回學校用之前，三個原則

1

學生個資不上傳

姓名、座號、家庭狀況，貼之前先拿掉。資料會送到國外的伺服器。

2

它會錯，老師把關

出的題、給的評語，看過才用，不直接發給學生。

3

當助手，不當老師

它省下的時間，拿去陪學生。

免費額度每天約 1000 次，個人備課夠用。要全校共用、或接進學校系統，請聯絡毛焦點。

課後可以試

  • 把公約改成另一個科目：數學應用題、英語單字造句、自然科的觀察紀錄
  • 把進階 2 的結果存成 CSV，用 Google 試算表打開
  • 有興趣接 LINE 的：收到訊息 → 丟進 chat() → 把回答推回去，一樣是一個網址、一把金鑰、一段 JSON
