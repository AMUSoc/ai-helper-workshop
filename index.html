API 就像餐廳的服務生

餐廳API 裡叫什麼今天對應的東西
你你的程式Postman、Colab 筆記本
菜單API 文件console.groq.com/docs
會員卡金鑰（API Key）gsk_ 開頭那一串
點餐單請求（request）你寄出去的 JSON
服務生APIapi.groq.com
廚房別人的伺服器＋模型Groq 機房裡的千問 Qwen3.8-27B
端上桌的菜回應（response）回來的 JSON，裡面有 content

一句話：菜單上沒有的不能點、要有會員卡、點錯會被退回。你不用知道廚房怎麼煮。

一個請求，只有四個零件

1

網址 URL

要找哪家餐廳。
https://api.groq.com/openai/v1/chat/completions

2

方法 Method

GET 是拿資料，POST 是送資料。跟 AI 講話一律 POST。

3

標頭 Headers

證明你是誰。
Authorization: Bearer 金鑰（Bearer 後面一個空格）

4

內容 Body

你要點什麼。一包 JSON，裡面是 model 和 messages。

按下去之後發生什麼

  1. 你的電腦把四個零件打包成一封信，寄到網址
  2. Groq 的門口先驗會員卡：對 → 放行；錯 → 退回，信封上寫 401
  3. 千問模型讀你的 messages，一個字一個字寫回答
  4. 回到你這裡：一包 JSON、狀態碼 200，通常 1–5 秒

慢，多半是它在寫長回答；錯，先看門口給的狀態碼（「卡住了」分頁有對照表）。

寄出去的、回來的，長這樣

你寄出的（請求）
{
  "model": "qwen/qwen3.8-27b",
  "messages": [
    {"role": "user",
     "content": "用一句話介紹你自己"}
  ]
}
它回來的（回應）
{
  "choices": [ {
    "message": {
      "role": "assistant",
      "content": "我是通義千問，一個大語言模型。"
    } } ],
  "usage": { "total_tokens": 31 }
}

兩邊都是「鑰匙：值」。寄出去是 user 說的話，回來是 assistant 說的話；usage 告訴你這次用了幾個 token。在 Python 裡拿那句話：r.json()["choices"][0]["message"]["content"]

API 文件怎麼看：只找三樣

1

網址在哪

文件叫它 endpoint。找 chat 或 completions 那一條，整串複製。

2

模型叫什麼名字

文件的 Models 頁。名字要一字不差：qwen/qwen3.8-27b

3

內容要長怎樣

找 messages 的範例，照它的格式填。多的參數先不要加。

額度與費用

問題答案
怎麼算錢不算「次」，算「字」，單位叫 token。一個中文字約 1–2 個 token
一篇作文用多少300 字作文進去 ＋ 300 字回饋出來 ≈ 1000 token
免費方案夠嗎每天約 1000 次請求、每分鐘 30 次。一天改 30 篇作文只用掉額度的 3%
為什麼會 429每把金鑰每分鐘有上限（qwen 約 30 次、輸出約 1000 字）。等 30–60 秒再按，一次不要要太長
付費多貴百萬 token 幾十塊台幣。個人備課不用花錢；全校共用再談

班級公約（system prompt）怎麼寫

公約三個部分：身分（它是誰、幫誰做事）、語氣（對幾年級講、什麼口吻）、規則（不能做什麼、輸出長什麼樣）。下面是填空版，複製後把〔 〕換掉就是你的小幫手。

公約填空版
你是「〔小幫手的名字〕」，一位國小老師的教學小幫手。
對象：國小〔幾〕年級學生。用字簡單、親切，一律使用繁體中文。
規則：
- 老師沒給的資料不要編；不確定就說不確定
- 回答用條列，每題附答案
- 回答不超過〔100〕字
- 語氣像這樣：「〔小明，你這段寫得很有畫面！〕」
1

給例子

與其說「語氣親切」，不如寫一句範例，它會模仿。

2

限制長度

「三句以內」「不超過 100 字」，不然它會寫一整頁。

3

要求格式

「用條列」「用表格」「每題附答案」，結果才能直接複製進考卷。

temperature：它要多「乖」

值結果適合
0.2每次答案幾乎一樣出題、改錯字、整理表格、「請照格式來」
0.5筆記本預設，中間值作文回饋、聯絡簿回覆
0.9每次都不一樣想故事開頭、作文題目靈感、「給我五個不一樣的」

這是程式裡唯一需要碰的數字，在「記憶」那格右邊的滑桿。

今天沒用到、但文件裡常見的參數

參數做什麼老師什麼時候會用
max_tokens回答最多幾個 token怕它寫太長，加硬性上限
temperature回答多隨機出題用低、找靈感用高
stream一個字一個字傳回來做聊天介面時，讓人不用等
response_format強迫回 JSON結果要直接進試算表或系統
reasoning_effort千問要不要「先想再答」今天設 none，回得快；要它解難題時拿掉這行

都是加在 body 裡的一行。文件的 Parameters 區塊有全部清單。

實作步驟 ‧ 跟著投影片走

五個步驟，一次一個

每一步都有「過關條件」。想看每個畫面長什麼樣、按哪裡，到「圖解步驟」分頁。過關了就等大家，沒過關先看「卡住了」分頁，再問旁邊的人，再舉手。

1

拿一把金鑰

AI 餐廳的會員卡。沒有它，服務生不會理你。
  1. 開 console.groq.com，用 Google 帳號登入
  2. 右上角點 API Keys → Create API Key，名稱隨便取（例如 class）
  3. 複製那串 gsk_ 開頭的金鑰，先貼到記事本。它只會顯示一次。（Colab 筆記本第 1 格右邊有一個框框，等一下就貼在那裡）

過關條件：記事本裡有一串 gsk_ 開頭的文字。

金鑰就是你的密碼。不截圖、不貼群組、不放進講義。課後回 Groq 刪掉重建。

2

用滑鼠跟 AI 說第一句話（Postman）

一個請求只有四個零件：網址、方法、標頭、內容。
  1. 開 postman.com → 右上 Sign In → Sign In with Google；第一次會問名字和用途，隨便填、按 Continue（詳細畫面在「圖解步驟」B）
  2. 進到工作區後，左上角 New → HTTP，方法選 POST，貼上網址
  3. Headers 分頁新增一列：Key 填 Authorization，Value 填 Bearer 你的金鑰（Bearer 後面一個空格）
  4. Body 分頁選 raw，右邊格式選 JSON，貼上下面那段，按 Send

3

同一件事，改用 Colab 做

筆記本是一個檔案，裡面是一格一格的程式。由上往下按，不跳格。

先懂這個就不會卡：上面的格子會把東西（例如金鑰）記住給下面的格子用。所以不要自己開空白筆記本、不要只貼一格，要打開我們做好的筆記本，從第 1 格開始按。

  1. 先登入 Google。到「開始前 10 分鐘」分頁的雲端資料夾，對 .ipynb 檔按右鍵 → 下載
  2. 開 colab.research.google.com，左上角 檔案 → 上傳筆記本，選剛下載的檔。上傳的就是你自己的，不用再存副本
  3. 第 1 格右邊有一個框框，把金鑰貼進去，按這格左邊的 ▶，下面出現「✅ 金鑰已設定」
  4. 第一次按會跳「這不是 Google 建立的筆記本」→ 按仍要執行（只問一次）
  5. 之後每一格都一樣：按 ▶ → 等左邊出現打勾 → 看格子下方的輸出。由上往下，一格跑完再按下一格

下面這段就是 Step 3 那一格的內容，已經在筆記本裡了，不用自己貼。看一下它跟 Postman 做的是同一件事：

筆記本 STEP 3 ‧ 跟 POSTMAN 做的是同一件事
import requests

URL = "https://api.groq.com/openai/v1/chat/completions"
headers = {"Authorization": "Bearer " + GROQ_API_KEY}
body = {"model": "qwen/qwen3.8-27b", "reasoning_effort": "none", "max_tokens": 600,
        "messages": [{"role": "user", "content": "用一句話介紹你自己"}]}

r = requests.post(URL, headers=headers, json=body, timeout=60)
print("狀態碼：", r.status_code)
print(r.json()["choices"][0]["message"]["content"])

對照看：URL 就是剛剛貼的網址、post 就是剛剛按的 Send、r.json() 就是剛剛看到的回應。

過關條件：Step 3 那一格下面印出 AI 回的一句話。上半場完成。

出現 NameError: … is not defined：代表上面的格子沒跑，回到第 1 格重新由上往下按。

4

寫班級公約，讓它記得對話

AI 本身不會記得；是我們每次把整本對話紀錄再寄一次，它才「記得」。

公約那一格：只改三個引號中間的中文，三個引號本身不要動。換名字、換年級、加規則都可以。改完按 ▶。

筆記本 ‧ 班級公約 ‧ 只改綠色的字
SYSTEM_PROMPT = """你是「小助」，一位國小老師的教學小幫手。
對象：國小中年級學生。用字簡單、親切，一律使用繁體中文、台灣用語。
規則：
- 老師沒有提供的資料不要自己編；不確定就說不確定
- 回答用條列，方便老師直接複製使用
- 出題要附答案與一句解析；作文回饋先講優點再講建議，語氣鼓勵
"""
messages = [{"role": "system", "content": SYSTEM_PROMPT}]

記憶那一格：程式藏起來了，按 ▶ 就好。右邊有一個 temperature 滑桿：0 很死板（出題、改錯字），1 很跳躍（想點子），預設 0.5。按完它會先自我介紹一次。它做的三件事：把你的話加進紀錄本、整本紀錄寄給 AI、把回答也記下來。

聊天那一格：右邊框框填一句話，按 ▶，它回一句。改框框的字、再按 ▶，可以一直聊，它記得前面說過的。試試看：先說「我教三年級國語」，貼一段課文請它出題，再問「我教幾年級？」它記得。（不用 while 迴圈加 input，是因為 Colab 的輸入框會卡住整本筆記本，下面的格子就按不動了。）

過關條件：它記得你教幾年級。覺得它講話太深或太淺，回公約那格改年級，重新按 公約 → 記憶 → 聊天 三格。

5

任務卡：餵它課文或作文

這是今天的主菜。

兩種用法：在聊天框直接貼課文或作文，再加一句指令（指令在「任務卡」分頁，有複製按鈕）；或用筆記本最下面的「一鍵任務卡」：右邊選一張卡、貼材料、按 ▶。不滿意就再講一句（「太難了，再簡單一點」、「第 3 題換一題」），它記得前面的內容。

過關條件：做完任何一張任務卡，而且有用「再講一句」修過一次結果。

helper.py 完整程式

跟筆記本的公約、記憶、聊天三格是同一份，只是合在一起、加上金鑰那一行。把金鑰貼進第 3 行的引號中間。

helper.py
import requests

GROQ_API_KEY = "gsk_把你的金鑰貼在這裡"
URL = "https://api.groq.com/openai/v1/chat/completions"
headers = {"Authorization": "Bearer " + GROQ_API_KEY, "Content-Type": "application/json"}

SYSTEM_PROMPT = """你是「小助」，一位國小老師的教學小幫手。
對象：國小中年級學生。用字簡單、親切，一律使用繁體中文。
規則：老師沒給的資料不要編；不確定就說不確定。
輸出用條列，方便老師直接複製。"""

messages = [{"role": "system", "content": SYSTEM_PROMPT}]

def chat(user_text):
    messages.append({"role": "user", "content": user_text})
    body = {"model": "qwen/qwen3.8-27b", "messages": messages,
            "reasoning_effort": "none", "temperature": 0.5, "max_tokens": 700}
    r = requests.post(URL, headers=headers, json=body, timeout=60)
    if r.status_code == 429:
        import time; print("（這一分鐘的額度用完了，等 30 秒…）"); time.sleep(30)
        r = requests.post(URL, headers=headers, json=body, timeout=60)
    if r.status_code != 200:
        messages.pop()
        return f"（出錯了：{r.status_code}）{r.text[:300]}"
    answer = r.json()["choices"][0]["message"]["content"]
    messages.append({"role": "assistant", "content": answer})
    return answer

print("跟小助聊天吧！（輸入 bye 結束）")
while True:
    text = input("老師：")
    if text.strip() == "bye":
        break
    print("小助：", chat(text))

一次改一整班

把作文放進清單，用迴圈逐篇送進去，結果存成檔案。每篇獨立記憶，所以每次重設 messages。
進階 2 ‧ 批次
作文們 = [
    "（第一篇作文貼這裡）",
    "（第二篇作文貼這裡）",
]

結果 = []
for i, 作文 in enumerate(作文們, start=1):
    messages = [{"role": "system", "content": SYSTEM_PROMPT}]   # 每篇重新開始
    回饋 = chat("給這篇三年級作文三個優點、兩個建議，語氣鼓勵，不要幫他改寫。\n\n" + 作文)
    結果.append(f"=== 第 {i} 篇 ===\n{回饋}\n")
    print(f"第 {i} 篇完成")

with open("作文回饋.txt", "w", encoding="utf-8") as f:

print("已存成 作文回饋.txt，左側「檔案」面板可以下載")

常見問題

我貼進去的課文會被拿去訓練嗎？

免費方案不一定。付費或企業方案通常承諾不拿你的資料訓練。所以：學生資料去識別化、公開布告欄能貼的才貼。

會不會突然要錢？

不會。Groq 免費方案沒有綁信用卡，超過額度只會回 429，不會扣款。

可以用 ChatGPT 的帳號嗎？

ChatGPT 網頁帳號不是 API 金鑰。OpenAI 的 API 要另外申請、要綁信用卡；今天用 Groq 就是為了免費、不綁卡。

金鑰不小心貼到群組了怎麼辦？

到 console.groq.com 把那把金鑰刪掉（Revoke），再建一把新的，筆記本第一格換掉就好。

為什麼每次重跑公約那格它就忘了？

因為 messages 清單被重設成只剩公約。這是設計，不是壞掉：想重來就重跑公約，想繼續就只跑聊天那格。

回答有簡體字或怪詞怎麼辦？

公約裡已經寫「一律使用繁體中文」；還是出現的話，再講一句「請用台灣的用語」。

可以不用 Colab、在自己電腦跑嗎？

可以。裝 Python，pip install requests，把「圖解步驟 E」的 helper.py 存成檔案執行，程式一模一樣。

可以接 LINE 嗎？

可以，但要一台一直開著的伺服器：收到訊息 → 丟進 chat() → 把回答推回去。這一步需要工程師，可以找毛焦點。

出的題、給的評語，看過才用，不直接發給學生。
